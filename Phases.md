# Phases.md

## Phase 1 — Discovery & verification
- Review the official Rajbiraj Expo website.
- Separate confirmed public facts from information that is not yet announced.
- Select only relevant event/trade/culture imagery.

## Phase 2 — Design system
- Dark premium visual direction.
- Glassmorphism surfaces, soft neumorphic depth, gradient accents and restrained animation.
- Responsive typography, spacing and accessible contrast.

## Phase 3 — Frontend implementation
- Semantic HTML5 structure.
- Responsive CSS for desktop/tablet/mobile.
- Mobile navigation.
- Demo update-subscription form with client-side validation.
- Developer-credit placement per device requirement.

## Phase 4 — Content & imagery
- Integrate official Rajbiraj Expo copy.
- Add relevant Unsplash images.
- Add alt text, image dimensions and lazy loading where appropriate.

## Phase 5 — QA
- Test 320px through large desktop widths.
- Keyboard navigation and reduced-motion checks.
- Validate links, forms, layout overflow and image behavior.
- Lighthouse performance/accessibility/SEO review.

## Phase 6 — Production launch
- Replace demo form with a secure production endpoint.
- Localize images and optionally fonts.
- Configure CSP/security headers, caching and compression.
- Add official dates, announcements, partners and venue only when confirmed.
